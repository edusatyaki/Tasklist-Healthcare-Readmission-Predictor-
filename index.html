Remove duplicate patients — keep only first encounter
Python
45m
Action Steps
  • Check how many unique patients: df['patient_nbr'].nunique() — expect ~71K vs 101K rows
  • Sort by encounter_id ascending (lowest = earliest encounter)
  • Drop duplicates on patient_nbr, keeping first
  • Record rows removed: print before and after shape
  • Document reasoning in notebook markdown: why first encounter avoids outcome leakage
Why This Matters
Statistical reason: Multiple encounters per patient make them non-independent observations. Including all encounters inflates sample size falsely and biases any model trained on this data. The first encounter represents the cleanest signal.

def classify_icd9(code):
try: code = float(code)
except: return 'Other'
if 250 <= code < 251: return 'Diabetes'
elif 390 <= code <= 459: return 'Circulatory'
return 'Other'
